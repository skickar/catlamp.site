// community_projects

Community projects

Builds and firmware from the community — student projects, experiments, and other open-source software that runs on the Sheen's ESP32-S3. Flash them here in your browser, or upload your own .bin.

!! not hardware-verified
Nothing here is tested or endorsed by Retia the way the official projects are. Community images can misbehave or fail to boot, and you'll confirm an "untested" warning before every flash. An ESP32-S3 is hard to truly brick — hold BOOT while plugging in to recover, then reflash an official build.
// featured

Featured student build

🌈
Newsheen RGBtastic
by sasquelch-digital · Meshtastic fork · pre-release v1.0.1

A Meshtastic fork that adds RGB light effects and remote control to the mesh — the 8 LEDs react to mesh activity, and you can drive them remotely from another node. Needs the optional LoRa radio (Wio-SX1262) fitted; attach a 915 MHz antenna before transmitting.

// other_firmware

Run other open-source firmware

The Sheen's brain is a standard ESP32-S3 (DevKitC-1, N16), so plenty of general-purpose ESP32 firmware runs on it. These aren't tuned for the Sheen out of the box — you'll usually set the LED pin to GPIO 16 (8 WS2812B), and the sensor header / radio pins yourself.

WLED (upstream)

The original project WLEDkitty is built on. Flash the stock release, then set the LED output to GPIO 16.

install.wled.me ↗
ESPHome

Wire the Sheen into Home Assistant as a light or sensor node with a YAML config.

web.esphome.io ↗
Tasmota (ESP32)

Lightweight smart-home firmware with a web UI and addressable-LED support.

tasmota install ↗
CircuitPython

Code the Sheen in Python. The Newsheen build is on the official list; upstream boards and libraries live at Adafruit.

circuitpython.org ↗
Matter smart light

Turn the Sheen into a Matter light and add it to Apple Home, Google Home, Alexa, or Home Assistant. There's a ready newsheen-matter-light build in the Newsheen release. Matter runs over Wi-Fi here — the ESP32-S3 has no Thread radio.

newsheen-matter-light ↗
