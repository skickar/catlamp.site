// community_projects

Community projects

Builds and firmware from the community — student projects, experiments, and other open-source software that runs on the Sheen's ESP32-S3. This is the unofficial shelf: a place to share what you've made and find what others are running.

!! not hardware-verified
Nothing here is tested or endorsed by Retia the way the official projects are. Community images can behave unexpectedly. Read the source, and flash at your own risk. An ESP32-S3 is hard to truly brick — hold BOOT while plugging in to recover, then reflash an official build.

// other_firmware

Run other open-source firmware

The Sheen's brain is a standard ESP32-S3 (DevKitC-1, N16), so plenty of general-purpose ESP32 firmware runs on it. These aren't tuned for the Sheen out of the box — you'll usually set the LED pin to GPIO 16 (8 WS2812B), and the sensor header / radio pins yourself. Great for tinkering.

WLED (upstream)

The original project WLEDkitty is built on. Flash the stock release, then set the LED output to GPIO 16.

install.wled.me ↗
ESPHome

Wire the Sheen into Home Assistant as a light or sensor node with a YAML config.

web.esphome.io ↗
Tasmota (ESP32)

Lightweight smart-home firmware with a web UI and addressable-LED support.

tasmota install ↗
CircuitPython

Code the Sheen in Python. The Newsheen build is on the official list; upstream boards and libraries live at Adafruit.

circuitpython.org ↗
